# summer-animated-page-yaz-donemi-animasyon-sayfasi-77
Yaz dönemi için tasarlanmış etkileyici animasyonlu bir web sayfası. Modern UI/UX prensipleriyle tasarlanmış olup, Vite, React, TypeScript, Tailwind CSS, Lucide React ve Framer Motion kullanılarak geliştirilecektir. 8px grid spacing, Glassmorphism ve Bento Grid düzeni gibi tasarım öğeleri içerir.
